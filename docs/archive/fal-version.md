# 開発履歴：Fal.ai 検証時代（2026-04-18 頃）

## 概要

Colab 移行の検討中、API サービスの Fal.ai を検証。
$10 課金してモデルを試したが、用途に合わず断念。

## 検証した構成

- **フロント**: Next.js（`ai-image-gen-fal`）
- **バックエンド**: Fal.ai API

## モデル別の検証結果

| モデル | 生成時間 | NSFW対応 | 評価 |
|---|---|---|---|
| `fal-ai/fast-sdxl` | 3.6秒 | ❌ 黒塗り | skinny等で NSFW 判定 |
| `fal-ai/realistic-vision` | 103秒〜タイムアウト | ✅ なし | キュー次第で不安定 |
| `fal-ai/flux/dev` | 3秒 | ✅ なし | 高速だが用途とミスマッチ |

## 致命的な問題

**プラットフォーム規制で NSFW 系が黒塗りになる**

- 全身グラビア系の画像生成という目的に対して致命的
- 課金しても規制は解除されない
- API 経由でも黒塗り判定が走る

## 移行理由

NSFW 用途では使えないと判断。
完全に自前で動かせる Vast.ai + A1111 への移行を決定。

## 学び

- マネージドサービスは速いが、コンテンツ規制を回避できない
- 本格的に自由度の高い生成をしたいなら、自前 GPU 必須
- $10 の検証コストで重要な学びが得られた

## 残された資産

- `ai-image-gen-fal` プロジェクト（参考用に残す可能性あり）
- Fal.ai の API 利用に関する知識
